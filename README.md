# 💱 Conversor de Câmbio

Uma aplicação web interativa para conversão de moedas em tempo real, desenvolvida com HTML, CSS e JavaScript.

## 📋 Sobre o Projeto

Conversor de Câmbio é uma aplicação útil e prática que permite converter valores entre diferentes moedas. Desenvolvida como parte do programa DevClub, demonstra o uso prático de JavaScript para criar aplicações interativas e funcionais.

## ✨ Características

- 💱 Conversão de moedas em tempo real
- 📱 Interface responsiva e intuitiva
- 🎨 Design moderno e clean
- ✅ Múltiplas moedas suportadas

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização e layout responsivo
- **JavaScript** - Lógica de conversão e interatividade

## 🚀 Como Usar

### Pré-requisitos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- JavaScript habilitado no navegador

### Visualizar o Projeto

1. Clone o repositório:
```bash
git clone https://github.com/BrunoRivaroli/devclub-conversor-de-cambio.git
```

2. Abra o arquivo `index.html` em seu navegador

3. Comece a converter moedas! 💱

### Como Usar a Aplicação

2. **Selecione a moeda de destino** no segundo dropdown
3. **Digite o valor** que deseja converter
4. **Veja o resultado** da conversão instantaneamente

## 🔧 Moedas Suportadas

O conversor suporta as principais moedas internacionais, incluindo:
- USD (Dólar Americano)
- EUR (Euro)
- GBP (Libra Esterlina)
- BRL (Real Brasileiro)

## 📝 Como Funciona

O conversor utiliza taxas de câmbio para realizar as conversões. A fórmula básica é:

```
Valor Convertido = Valor Original × (Taxa da Moeda Destino / Taxa da Moeda Origem)
```
